## AnyDroid 是干什么的，你花钱买到的是哪部分

AnyDroid 是 iMobie 出的一款电脑端安卓数据管理软件，Windows 和 macOS 都有版本。手机连上电脑后能做的事大致是这些：

- 备份与导出：整机备份，或者按照片、联系人这类分类单独备份到电脑，导成常见格式
- 应用管理：批量安装、卸载、备份手机里的 App
- 文件整理：把散在各处的文件归进文件夹，按关键词搜
- 无线连接：扫二维码连手机，不插数据线也能传文件
- 手机对手机：两台手机都装上 App，直接互传照片视频和文档
- iPhone 转安卓：从 iPhone、iPad、iTunes 或 iCloud 迁数据到安卓机，iOS 的媒体格式自动转成安卓能直接用的
- 本地传输：数据在你电脑和手机之间走，不上传到云端

功能表看着长，真正值得掏钱的是两件。一是 iPhone 换安卓时的格式转换，几百条 HEIC 照片和 MOV 视频手工转一遍很花时间。二是电脑端的批量整理，用系统自带的文件管理器从手机拖几千张照片，慢，中途断了还得重来。

其余功能属于"有更好，没有也能凑合"。手机对手机互传，微信文件传输助手和各厂商的互传功能都能顶一阵。无线扫码连接是加分项，它省掉的是找数据线的麻烦，不是必需品。
